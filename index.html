1. ベースフォント

TTFをドラッグ＆ドロップ または「フォントを開く」。Noto Sans JP / 明朝 / ゴシック等の .ttf（TrueType輪郭）

2. 対象の文字

旧字体にしたい文字（先生が実際に入力する新字体）を1字。

編集した文字（差し替えリスト）

まだありません

作業は .json で保存。次回このファイルとフォントを読めば続きから編集できます。

3. 部品を借りる文字（ドナー）

部品の供給元にする文字、または既存の旧字体を1字。

4. 反映する

丸ごと置換＝既存の旧字体をそのまま使う最短ルート。コピー＝部品だけ流用して組む。

5. 書き出し

編集した字だけを差し替え、他のグリフ・cmap・IVSは元のまま温存します（A方式）。

使い方

① TTFを開く → ② 対象の文字（新字体）を開く → ③ ドナー文字を表示 → ④ 輪郭を選んでコピー、または丸ごと置換 → 位置を合わせる → ⑤ 書き出す。

中央キャンバス操作

クリック 輪郭/点を選択 ドラッグ 移動 ← ↑ → ↓ 1単位移動 Shift+矢印 10単位 Delete 選択輪郭を削除 Space+ドラッグ 画面移動 ホイール 拡大縮小 Esc 選択解除

対応フォント：TrueType輪郭（glyf）の .ttf。游明朝/游ゴシック/IPAex/Noto Sans JP(static) 等。CFF形式(.otf) は本ツール非対応です。

書き出し後は必ず FontForge か Windows で開いて表示を確認してください（本ツールは書き出し直後に内部で自己検証も行います）。
