1. ベースフォント

TTFをドラッグ＆ドロップ または「フォントを開く」。Noto Sans JP / 明朝 / ゴシック等の .ttf（TrueType輪郭）

2. 対象の文字

旧字体にしたい漢字を入力（複数可）。開くと下の編集リストに未編集で並び、先頭の字が編集用に開きます。

編集リスト

編集済み未編集
「対象の文字」で漢字を入力して開くと、ここに並びます

旧字体・異体字の候補

このフォントに収録されている、対象文字の旧字体/異体字です。「置換」で一発完了、「借用」で部品取りに使えます。

3. 部品を借りる文字（ドナー）

部品の供給元にする文字、または既存の旧字体を1字。表示された字は直接クリックで部品選択できます。

4. 反映する

丸ごと置換＝既存の旧字体をそのまま使う最短ルート。コピー＝部品だけ流用して組む。

5. 書き出し

編集した字だけを差し替え、他のグリフ・cmap・IVSは元のまま温存します（A方式）。

編集した字を U+E000 から順に私用領域(PUA)へ割り当て、Windows外字(EUDC)用の .tte を作成します。使用側でIMEへの外字登録／EUDC登録が必要です。正規Unicodeを持つ旧字体の配布には通常のTTF書き出しを使ってください。

作業ファイル

作業JSONをドラッグ＆ドロップ またはクリックして読み込み。保存した .json で続きから編集できます

「別フォントへ流用」は別フォントを開いた状態で使うと、旧字体化を自動で再現します。

使い方

① TTFを開く → ② 対象の文字（新字体）を開く → ③ ドナー文字を表示 → ④ 輪郭を選んでコピー、または丸ごと置換 → 位置を合わせる → ⑤ 書き出す。

アウトライン編集（点ベース）

クリック 点/辺/内側を選択 空きをドラッグ 範囲選択 Shift+クリック 追加選択 辺をドラッグ 両端の点ごと移動 Ctrl+A 全点選択 ← ↑ → ↓ 選択点を移動（Shiftで10） Delete 選択点を削除 C 選択点を 直線↔曲線 Ctrl+C / Ctrl+V 点をコピー／貼付（切り抜き） Ctrl+Z / Ctrl+Shift+Z 戻す／やり直し

道具 V選択 T自由変形 R回転 A角点追加 S曲線点追加 Space画面移動 [ ]回転(Shiftで15°)

切り抜き（例：車の中の田だけ欲しい）：範囲選択などで田を構成する点を選び Ctrl+C。対象の文字を開いて Ctrl+V。選んだ点は輪郭として閉じられ、切り出した形が貼り付きます。

自由変形：Tで変形ツール。選択（なければ全体）に枠が出るので、角ハンドルで縦横同時、辺ハンドルで片方向、Shiftで等比拡大縮小。※太さも一緒に拡縮されます（線幅一定の変形はしません）。

作業履歴JSON は画面のどこにでもドラッグ＆ドロップで読み込めます。

旧字体候補：対象文字に、フォント内の旧字体・異体字（別コード or IVS）があれば右上に表示。「置換」で一発、「借用」で部品取りに使えます。

別フォントへ流用：作成後に「作業を保存」でjson化。別の明朝/ゴシックを開いて「別フォントへ履歴を流用」を押すと、旧字体化した文字を新フォント側の字形で自動的に作り直します（外見はコピーせず、操作＝レシピを再生）。手作業で点を動かした字は「要確認」として案内します。

対応フォント：TrueType輪郭（glyf）の .ttf。游明朝/游ゴシック/IPAex/Noto Sans JP(static) 等。CFF形式(.otf/Noto Sans CJK) は非対応。可変フォント(VF)は既定インスタンスにのみ適用（静的化推奨）。

書き出し後は必ず FontForge か Windows で開いて表示を確認してください（本ツールは書き出し直後に内部で自己検証も行います）。
