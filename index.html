1. ベースフォント

TTFをドラッグ＆ドロップ または「フォントを開く」。Noto Sans JP / 明朝 / ゴシック等の .ttf（TrueType輪郭）

2. 対象の文字

旧字体にしたい漢字を入力（複数可）。開くと下の編集リストに未編集で並び、先頭の字が編集用に開きます。

編集リスト

編集済み未編集
「対象の文字」で漢字を入力して開くと、ここに並びます

旧字体・異体字の候補

このフォントに収録されている、対象文字の旧字体/異体字です。「置換」で一発完了、「借用」で部品取りに使えます。

3. 部品を借りる文字（ドナー）

部品の供給元にする文字、または既存の旧字体を1字。表示された字は直接クリックで部品選択できます。

4. 反映する

丸ごと置換＝既存の旧字体をそのまま使う最短ルート。コピー＝部品だけ流用して組む。

5. 書き出し

作業ファイル

作業JSONをドラッグ＆ドロップ またはクリックして読み込み。保存した .json で続きから編集できます

別フォントを開いた状態で設定JSONを読み込むと、JSONに記録された編集記録を基に旧字体化を自動で再現します。

ヘルプ

基本の流れ

① TTFを開く→ ② 対象の文字を開く→ ③ ドナー／部品を表示→ ④ 輪郭をコピー／丸ごと置換→ ⑤ 位置合わせ→ ⑥ 書き出す

旧字体候補・一括変換・部品パレット

旧字体候補：対象文字に旧字体・異体字（別コード or IVS）があれば右上に一覧表示。複数あるときは字形を見て選べます。「置換」で丸ごと、「借用」で部品取りに使えます。

一括変換（編集リスト上部の橙ボタン「旧字体へ一括変換」）：未編集の字を候補で自動変換します。候補が複数ある字や文脈依存の字（弁＝辨/瓣/辯、余、予 など）は自動変換せず、右の候補一覧から手動で選ぶ運用です。

部品パレット：右カラム「3. ドナー」の「部品パレットから選ぶ」で、旧字体作成によく使う偏旁・要素を一覧から選べます。字形は読み込んだフォントから採るので、明朝／ゴシック等に自動で揃います。

アウトライン編集（点・辺・選択）

クリック 点/辺/内側を選択 空きをドラッグ 範囲選択 Shift+クリック 追加選択 辺をドラッグ 両端の点ごと移動 ドラッグ中に Shift 水平/垂直/45°に拘束 Ctrl+A 全点選択 ← ↑ → ↓ 選択点を移動（Shiftで10） Delete 選択点を削除 C 選択点を 直線↔曲線 Ctrl+C / Ctrl+V 点をコピー／貼付（切り抜き） Ctrl+Z / Ctrl+Shift+Z 戻す／やり直し

点を選ぶと画面下の情報バーに座標が出ます。1点なら X / Y、複数点なら選択範囲の 左・右・上・下 と 幅×高 を表示。同じ高さ・同じ幅にそろえる、左右対称パーツを数値で確認する、といった位置合わせの目安になります（ドラッグ中もリアルタイムに更新）。

道具（ショートカット）

V選択　T自由変形　R回転　A角点追加　S曲線点追加　Kはさみ　Pフリーハンド　Space画面移動　[ ]回転(1°・Shiftで15°)　F全体表示

「合体」ボタンは選択した複数図形をアウトライン統合します（下記）。

はさみ・自由変形・切り抜き

はさみ（K）：輪郭上の2点をクリックすると、その2点で1つの閉じた輪郭を2つに分割します（長い四角→2つの四角、対角の2点→2つの三角）。角にスナップし、辺の途中でも切れます。同じ辺だけ・同じ点は分割できません。1点目を決めた後に Shift を押すと、マウスの向きに応じて水平/垂直に切断線が拘束され、輪郭との交点へ吸着します（黄色い目印が出ます）。平行・垂直にきれいに切りたいときに使います。

自由変形（T）：選択（なければ全体）に枠が出ます。角ハンドルで縦横同時、辺ハンドルで片方向、Shiftで等比拡大縮小。※太さも一緒に拡縮されます（線幅一定の変形はしません）。

切り抜き（例：車の中の田だけ欲しい）：範囲選択で田を構成する点を選び Ctrl+C。対象の文字を開いて Ctrl+V。選んだ点が輪郭として閉じ、切り出した形が貼り付きます。

フリーハンド（P）：キャンバス上をドラッグして輪郭をなぞり、指を離すと自動で閉じた図形になります。手ブレは自動で間引かれ、少ない角点のきれいな輪郭になります。細かな調整は選択ツールで点を動かして仕上げてください。

合体（アウトライン統合）：重ねた図形を2つ以上まるごと選択して「合体」ボタンを押すと、外形だけを1つのアウトラインに統合します（Illustratorのパスファインダー「合流」に相当）。まるごと選択は、範囲選択で囲むか、各図形の内側を Shift+クリック で追加します。巻き方向が逆でも正しく統合され、囲まれた空白は穴として保持されます。重なりで塗りが消えるのは輪郭の巻き方向が逆で打ち消し合うためで、合体すると正しい向きの単一輪郭になり解消します。曲線は、重なりで切断されない辺は元の曲線点のまま保持されます。図形が交差する接合部の辺だけは直線化されます（交点は新しい点のため）。滑らかさが必要な接合部は、統合後にその数点を C で曲線化してください。

作業ファイル・別フォントへ流用

作業を保存で作業JSONを書き出せます（画面のどこにでもドラッグ＆ドロップで読み込み可）。

別フォントへ流用：別の明朝／ゴシックを開いた状態で実行すると、旧字体化を新フォント側の字形で自動的に作り直します（外見をコピーするのではなく、操作＝レシピを再生）。手作業で点を動かした字は「要確認」として案内します。

対応フォントと確認

TrueType輪郭（glyf）の .ttf に対応（游明朝／游ゴシック／IPAex／Noto Sans JP static 等）。CFF形式（.otf / Noto Sans CJK）は非対応。可変フォント（VF）は既定インスタンスにのみ適用（静的化推奨）。

ベースに何を使うか（重要）：漢字だけでなくラテン・かなも入った完全なフォントをベースにしてください（PowerPoint埋め込み対策）。おすすめは 言語版「Noto Sans JP」（約1.7万字）です。pan-CJKの「Noto Sans CJK JP」は約6.5万字超で、1つのTTFに収まる上限（65535グリフ）を超えるため単一のTTFにはできません（FontForgeで「単一化」しても『グリフが多すぎます』で失敗します）。CIDの下位フォント（Ideographs等）だけを取り出すと漢字専用になり、これがPowerPointで置換される一因になります。

中身がCFFの.ttfを渡された場合（拡張子は.ttfでも実体はOTTO＝CFF）：本ツールは弾きます。FontForgeで開き、EMを2048にしてから「ファイル → フォントを出力 → TrueType(TTF)」で書き出すとglyf化されて使えるようになります（検証ダイアログが出たら「生成」で進めてOK）。

書き出し後は FontForge か Windows で開いて表示を確認してください（本ツールも書き出し直後に内部で自己検証します）。配布用に整える手順は「OTF⇒TTF変換案内」タブを参照。

外字ファイル（.tte）を Windows の IME に追加する

「外字ファイルを書き出す（.tte）」で作られる .tte は、編集した字を 私用領域（PUA・U+E000〜E0FF）に割り当てた外字（EUDC）フォントです。Windowsに登録すると、どのアプリでもIMEから入力できるようになります（Windows前提）。

1置き場所を決める。書き出した .tte を分かりやすい場所（例 C:\Windows\Fonts\EUDC\MyGaiji.tte）に置きます。EUDCフォルダが無ければ作成します。

2レジストリに登録する。regedit で HKEY_CURRENT_USER\EUDC\932 を開き（無ければ 932 キーを作成）、システム全体で使うなら文字列値 SystemDefaultEUDCFont に .tte のフルパスを設定します。特定フォントにだけ紐づけるなら、値名を対象フォント名（例 游明朝）にしてパスを設定します。設定後はサインアウト／再起動で反映されます。

3IMEで入力する。Microsoft IMEで割り当てコード（例 E000）を入力し F5 を押すと、コードポイントから外字を変換・入力できます。または「がいじ」と入力して F5／Ctrl+F10 で IMEパッド → 文字一覧 を開き、フォントに「全フォント（外字）」を選んで一覧から選びます。登録状況は charmap（文字コード表）でフォントに「全フォント（外字）」を選んでも確認できます。

注意：Microsoftは .tte を手動コピー／レジストリ直接編集で入れる方法を正式サポートしていません（設定を誤るとサインインに支障が出ることがあります）。作業前に該当レジストリキーをエクスポートしてバックアップし、正式には 外字エディター（eudcedit）→「ファイル → フォントのリンク」での紐づけも検討してください。

このガイドの要点

本ツールは、あなたが編集した字形（glyf）だけを差し替え、名前やOS/2などの情報は元のまま引き継ぎます。

つまり 入力するTTFの情報が正しくないと、その誤りもそのまま残ります。編集を始める前に、FontForge で「正しい情報を持つベースTTF」を作っておくのがコツです。

0. まず「使えるフォント」を用意する

◆ 形式
TrueType（glyf）の .ttf が必要です。中身がCFFの .otf（拡張子が.ttfでも中身がCFFのもの）は使えません。→ FontForgeでglyf形式に変換します（下記ステップ）。

◆ 収録文字
漢字だけでなく ラテン・かな・約物もそろった“完全版” を使ってください。
漢字だけの版は、PowerPointに埋め込んだとき別フォントに置き換わる不具合が出ます。

◆ サイズ上限
1つのTTFに入るのは 約6.5万字（65,535）まで。
pan-CJKの「Noto Sans CJK JP」は6.5万字を超えるため 1つのTTFにできません（単一化してもTTF書き出しで失敗）。
→ おすすめは言語版の 「Noto Sans JP」（約1.7万字・ラテン/かな/漢字入り） です。

ステップ1：FontForgeでベースTTFを作る

1OTFを開く
大元のフォント（例：Noto Sans JP）をFontForgeで開きます。

2【CIDフォントのとき】CID →「単一化」
フォントが下位フォント（Alphabetic / Kana / Ideographs …）に分かれていてメニューがグレーで押せない場合は、上部メニューの 「CID → 単一化」 を実行します。
これで全部が1つに統合されて ラテン・かな・漢字がそろい、さらに グレーで押せなかった項目（TTF名など）も編集できるようになります。
※「Noto Sans CJK JP」は単一化すると6.5万字を超え、後の書き出しで「グリフが多すぎます」と失敗します。その場合は言語版「Noto Sans JP」を使ってください。
※もともと1つの言語版フォントなら、この手順は不要です。

3EM（文字の基準サイズ）を 2048 にする
「エレメント → フォント情報 → 一般」で 「EMの大きさ」を 2048 に変更します（元は通常1000）。
このとき 「アウトラインを一緒に拡大（スケール）する」を選び、字形も一緒に拡大してください。TrueTypeでは2048が標準で、表示が安定します。

4フォント名を独自名にする（元との衝突を防ぐ）
「エレメント → フォント情報」を開き、「PS Names」と「TTF名」の両方に独自の名前（例 Kyujitai-Regular）を入れます。
・スタイル（サブファミリー）は必ず Regular だけ に。
・「TTF名」の値は最初PostScript名に連動して変更できないので、直したい行の 「文字列」列を右クリック →「PostScript名から切り離す」 を選んでから編集します。

5日本語フラグを直す
「フォント情報 → OS/2 → 文字セット」右下の「コードページ」で 「932, 日本語」だけをON にします。
「950, 繁体字中国語」など日本語以外がONなら Ctrl+クリックで解除します（PowerPointで「選べるが適用されない」不具合の原因）。

6行の高さ（縦メトリクス）は原則そのまま
正しく作れたフォントには適切な行の高さが入っているので、基本は触りません。
行間が実際におかしいときだけ調整します（本ツールの「書き出し前の設定確認」の折りたたみ内で微調整できます）。

7TrueTypeで書き出す
「ファイル → フォントを出力 → TrueType(TTF)」で書き出します（例 Base_Kyujitai.ttf）。
検証ダイアログ（Self Intersecting 等）が出たら 「生成」 で進めてOK。CFF（3次曲線）はここでTrueType（2次曲線）へ自動変換されます。

【重要】ライセンスで触ってはいけない所・守ること
改変したフォントを配布・納品するときは、元フォントのライセンスに従う必要があります。

■ Noto Sans JP（SIL OFL 1.1）を使う場合
・著作権・ライセンス表示は消さない：フォント情報「TTF名」内の Copyright（著作権）／License（ライセンス本文）／License URL はそのまま残します（削除・改変は規約違反）。
・フォント名は必ず変える（手順4）。「Noto」等の名前をそのまま使わない。
・改変版も 同じOFLで配布 し、フォント単体を有償で売らない（他の成果物に同梱するのは可）。

■ 他のフォントに変える場合
・游明朝／游ゴシック（Windows同梱）や市販フォントの多くは 改変・再配布が禁止 です。
・使う前に必ず、そのフォントが 「改変」と「再配布（埋め込み配布）」を許可 しているか確認してください。ここは技術ではなく権利の問題で、最優先です。

ステップ2：本ツールで編集

スタイル・文字範囲（PowerPoint埋め込み対策）

PowerPointは埋め込みフォントの照合が厳しく、フォントの「自分が何者か」の情報が欠けていると、名前は正しいのに別のフォントに置き換わって字形が反映されないことがあります。下の2つを入れておくと、その照合が通りやすくなります。

このフォントは「標準（Regular）」の目印が無い状態です。PowerPointでの置き換わりの一因になり得ます。上のチェックを入れることを推奨します。

「標準として登録」＝Regularの目印(REGULARビット)を立てます。「文字範囲を設定し直す」＝実際に入っている文字（かな・漢字・英字など）に合わせて範囲情報を作り直します。どちらも太字/斜体ではない通常のフォント向けの安全な設定です。

個別に書き出す（TTFなしで単体出力）

編集した字を U+E000 から順に私用領域(PUA)へ割り当て、Windows外字(EUDC)用の .tte を作成します。使用側でIMEへの外字登録／EUDC登録が必要です。正規Unicodeを持つ旧字体の配布には通常のTTF書き出しを使ってください。
